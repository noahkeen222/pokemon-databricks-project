# Pokémon Data Visualization Project

## Summary:
This is my Pokémon data visualization project that I built to get familiar with the Databricks platform. I took data from a Kaggle Pokémon data set, uploaded it to a Databricks volume, then ingested it to bronze, normalized it into silver, and made analytics gold tables.

The visualizations show a breakdown of total stats by type, generation, and legendary status to have a dashboard view of variance between these categories.

There are also visualizations of the vowel / consonant count for type, generation, and legendary Pokémon, showing the variance in naming conventions.

This was all done via the Databricks Free Edition via the web browser.
